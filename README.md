# Telegram AI-бот

## Railway

1. Загрузите проект в GitHub и подключите репозиторий в Railway.
2. В настройках сервиса Railway откройте **Variables** и добавьте:
   - `BOT_TOKEN` — токен Telegram-бота;
   - `GEMINI_API_KEY` — ключ Gemini.
3. Выполните деплой. Команды сборки и запуска уже указаны в `railway.toml`.

Бот использует только стандартные модули Python, поэтому дополнительные пакеты не нужны.
Не загружайте настоящие ключи в GitHub. Файл `.env.example` содержит только имена переменных;
локальный `.env` и `config.py` исключены через `.gitignore`.

`ADMIN_ID`, напоминания и сохранение данных пока не реализованы.
